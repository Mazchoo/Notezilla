
## Quiz

Quizes are multiple choice questions where one of multiple choices are correct or incorrect. There is reveal button for each question and when it is revealed correct answers are formatted differently to incorrect answers. Answers that have the first point as a `+` are expected to be selected and ones with `-` expect not to be selected. Answers will show show an explanation when the expected answer is selected and optionally an explanation when the expected one is not selected.

Lock the document to try the quiz out.

```quiz
This is a question
Answer A
  + Explanation of why it is correct
Answer B
  + When selected (correct)
  When not selected
Answer C
  - Explanation why it is wrong
Answer D
  - Not selected, correct
  Explanation when selected

This is another question
Answer A
  - Explanation of why it is correct when not selected
Answer B
  + When selected (correct)
```
